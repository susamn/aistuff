# Example Prompts for Skill Importer

## 1. Import from GitHub Repository
"Import skill from https://github.com/user/git-review-skill.git"

## 2. Import from Local Directory
"Import the new skill located at /tmp/downloads/custom-critic-skill"

## 3. Import from Web Page or URL
"Import skill from https://raw.githubusercontent.com/example/skills/main/code-cleaner/SKILL.md"

## 4. Import with Subpath
"Import skill from https://github.com/user/mono-repo.git with subpath skills/security-auditor"
