# Systemd Service Creator

This skill governs scaffolding, installing, and auditing personal systemd service and timer unit files across your workspace applications.

---

## 1. Architecture & Tagging Contract

All personal services and timers registered by workspace applications are tagged and grouped using systemd's target dependency mechanism:

- **Target Grouping (`personal-services.target`):**
  Every personal service or timer generated by this skill includes `personal-services.target` under `[Install] WantedBy=`:
  ```ini
  [Install]
  WantedBy=multi-user.target personal-services.target  # Services
  WantedBy=timers.target personal-services.target      # Timers
  ```
- **Discovery in `linux-system-manager`:**
  `linux-system-manager` scans `personal-services.target` dependencies directly via `systemctl list-dependencies personal-services.target`. Any app installing a unit attached to this target automatically appears under **Section 5 (Personal Services & Timers)**.

---

## 2. Hardening & Guardrail Rules

1. **Security Sandbox Defaults:**
   Generated `.service` units include standard security options:
   `ProtectSystem=strict`, `ProtectKernelTunables=true`, `ProtectKernelModules=true`, `ProtectControlGroups=true`, `PrivateDevices=true`, `NoNewPrivileges=true`.
2. **Template Units (`app@.service`):**
   Always use `%i` (lowercase) for instance names in `ExecStart` and `Description`. Systemd path-unescapes `%I` (uppercase), translating dashes (`-`) to slashes (`/`), which breaks config resolution for profiles with dashes.
3. **Mount Services:**
   For foreground FUSE mounts (like `rclone`), add `SuccessExitStatus=143 SIGTERM` and an `ExecStopPost` cleanup command to prevent clean shutdowns from recording false failures in systemd.

---

## 3. Workflow

### Scaffolding New Units
To create unit files for an app:
```bash
<SKILL_PATH>/scripts/manage.py scaffold \
  --name my-app \
  --exec "$WORKSPACE_PATH/services/my-app/run.sh" \
  --unit-type both \
  --schedule daily \
  --output-dir "$WORKSPACE_PATH/services/my-app"
```

### Installing and Enabling
To copy a unit file to `/etc/systemd/system/`, reload systemd, and enable `personal-services.target`:
```bash
sudo <SKILL_PATH>/scripts/manage.py install --file "$WORKSPACE_PATH/services/my-app/my-app.service"
```

### Listing Personal Services
To list all active and inactive personal units attached to `personal-services.target`:
```bash
<SKILL_PATH>/scripts/run.sh analyze
<SKILL_PATH>/scripts/run.sh summary /tmp/systemd_service_creator_artifact.json
```
